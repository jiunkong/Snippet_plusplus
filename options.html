기본 문법

트리거는 직접 입력하는 단축어이고, 본문은 대신 삽입할 텍스트입니다. 본문의 {{…}} 안에 변수·계산식·함수 등을 적습니다.

텍스트와 태그

text {{expression}}

일반 텍스트는 그대로 삽입됩니다. 태그 안의 계산 결과는 텍스트로 바뀌어 삽입됩니다.

예제 보기
트리거
/total
본문
Total: {{2 + 3}}
직접 입력할 텍스트
/total
결과
Total: 5

문자열과 함수 인수

"text" · 'text' · function(arg1, arg2)

문자열은 큰따옴표 또는 작은따옴표로 감쌉니다. 함수의 인수는 쉼표로 구분합니다. 따옴표는 반드시 닫아야 하며, 문자열 안의 같은 따옴표 앞에는 역슬래시(\)를 붙입니다.

예제 보기
본문
{{replace("Hello, world", "world", "Guest")}}
결과
Hello, Guest

트리거에서 변수 받기

입력한 텍스트의 일부를 변수에 담아 본문에서 재사용할 수 있습니다.

캡처와 변수 사용

${name:regex:flags} → {{$name}}

트리거에 변수 이름과 정규표현식을 적고, 본문에서는 $이름으로 읽습니다. 플래그는 생략할 수 있습니다. 예를 들어 \d+는 한 자리 이상의 숫자를 받습니다.

예제 보기
트리거
/issue ${id:\d+}
본문
Issue #{{$id}}
직접 입력할 텍스트
/issue 123
결과
Issue #123

변수·연산·범위·리스트

캡처한 값이나 직접 저장한 값을 계산에 사용할 수 있습니다.

값 없이 변수 선언

{{set $name}}

값을 생략하면 undefined가 저장됩니다. 변수는 나중에 값을 넣어 사용할 수 있고, 값을 넣기 전에 출력하면 빈 문자열이 됩니다. 기존 변수에 다시 사용하면 값이 undefined로 초기화됩니다.

예제 보기
본문
{{set $value}}{{type($value)}}
결과
undefined

변수 저장과 수정

{{set $name = expression}}

set은 값을 저장하고 본문에는 아무것도 삽입하지 않습니다. 이미 있는 값은 +=, -=, *=, /=, %=로 수정할 수 있습니다. 쉼표로 여러 할당이나 선언을 나눌 수 있습니다. 예: {{set $a = 3, $b = 5}}. 왼쪽부터 순서대로 적용하므로 뒤의 식에서 앞에서 바꾼 값을 사용할 수 있습니다. 문자열·함수·리스트 안의 쉼표는 할당을 나누지 않습니다.

예제 보기
본문
{{set $a = 3, $b = 5}}{{$a}} + {{$b}} = {{$a + $b}}
결과
3 + 5 = 8

계산과 비교

+ - * / % · == != > >= < <= · && || !

괄호로 계산 순서를 정합니다. 비교에는 ==를 사용하고, 여러 조건은 &&(그리고), ||(또는)로 연결합니다. 조건 ? 참일_때 : 거짓일_때 형식도 사용할 수 있습니다. 문자열에 0 이상의 정수를 곱하면 반복합니다. "ab" * 3 또는 3 * "ab"의 결과는 "ababab"입니다. 0번 반복하면 빈 문자열이 되며, *=에도 적용됩니다.

예제 보기
본문
Average: {{(80 + 100) / 2}}
결과
Average: 90

정수 범위(range)

start~end

양 끝을 포함하는 정수 범위입니다. 2~5는 2, 3, 4, 5를 뜻하며 5~2처럼 역순도 가능합니다. 양 끝에 변수나 계산식을 쓰고, 범위를 변수에 저장하거나 random(), for, 스니펫 함수에 전달할 수 있습니다.

예제 보기
본문
{{set $min = 2}}
{{set $range = $min~($min + 3)}}

$range에 2~5 범위가 저장됩니다. 아래의 반복하기와 무작위 선택에서 사용할 수 있습니다.

반복 가능한 값(iterable)

list와 string은 iterable입니다. for로 원소를 순회하고 insertAt·removeAt으로 편집한 새 값을 만들 수 있습니다. range는 readonly iterable로, for와 len은 지원하지만 원소 삽입·제거는 지원하지 않습니다. type()은 구체적인 타입인 list·string·range를 반환합니다. 문자열 순회·삽입·제거와 len은 유니코드 코드 포인트 단위입니다.

리스트 저장과 사용

{{set $items = [1, 2, 3]}}

대괄호 안에 쉼표로 원소를 구분합니다. 숫자·문자열·변수·계산식·다른 리스트를 넣을 수 있고, []는 빈 리스트입니다. type()은 list, len()은 원소 개수를 반환합니다. 직접 출력하면 [1,2,3] 형태로 표시하며 문자열 원소에는 큰따옴표가 붙습니다.

예제 보기
본문
{{set $items = [1, 2, 3]}}\
{{type($items)}} / {{len($items)}} / {{$items}}
결과
list / 3 / [1,2,3]

리스트 연결

list + list · {{set $items += [value]}}

두 리스트를 이어 붙인 새 리스트를 반환합니다. 원본은 바뀌지 않습니다. 양쪽 값이 모두 list여야 합니다.

예제 보기
본문
{{([1, 2] + [3, 4])}}
결과
[1,2,3,4]

값으로 원소 제거

list - list · {{set $items -= [value]}}

오른쪽 리스트의 값과 같은 원소를 모두 제거한 새 리스트를 반환합니다. 원본과 나머지 원소의 순서는 유지합니다.

예제 보기
본문
{{[1, 2, 2, 3] - [2]}}
결과
[1,3]

인덱스로 원소 삽입

insertAt(iterable, index, value)

list 또는 string의 해당 인덱스 앞에 값을 삽입하여 같은 타입의 새 값을 반환합니다. list에는 원소 하나를 넣고 string에는 str(value)로 변환한 문자열을 넣습니다. len(target)은 맨 뒤, -1은 마지막 원소 앞입니다. 빈 값에는 0으로 삽입합니다. 정수 인덱스만 허용하며 범위 밖이면 내용은 그대로입니다. 문자열 위치는 유니코드 코드 포인트 단위입니다. range는 읽기 전용이므로 사용할 수 없습니다.

예제 보기
본문
{{set $items = [10, 30]}}\
{{set $items = insertAt($items, 1, 20)}}\
{{$items}}
{{insertAt("AC", 1, "B")}}
결과
[10,20,30]
ABC

인덱스로 원소 제거

removeAt(iterable, index)

list 또는 string의 해당 인덱스 원소 하나를 제거하여 같은 타입의 새 값을 반환합니다. 0은 첫 번째, -1은 마지막 원소입니다. 정수 인덱스만 허용하며 범위 밖이면 내용은 그대로입니다. 문자열 위치는 유니코드 코드 포인트 단위입니다. range는 읽기 전용이므로 사용할 수 없습니다. 원본은 바뀌지 않으므로 결과를 다시 할당하세요.

예제 보기
본문
{{set $items = [10, 20, 30]}}\
{{set $items = removeAt($items, -1)}}\
{{$items}}
{{removeAt("A😊B", 1)}}
결과
[10,20]
AB

iterable 원소 읽기

$items[0] · $items[-1] · $items[1][0]

list·string·range에 [index]로 접근합니다. 인덱스는 0부터 시작하며 -1은 마지막 원소입니다. 문자열은 유니코드 코드 포인트 단위이고 range는 순회 순서의 숫자를 반환합니다. 인덱스는 정수여야 하며 범위를 벗어나면 undefined를 반환합니다. 캡처한 숫자 문자열은 num()이나 int()로 변환하세요.

예제 보기
본문
{{set $items = ['red', 'blue', 'green']}}\
{{$items[0]}} / {{$items[-1]}}
{{"A😊B"[1]}} / {{(5~2)[-1]}}
결과
red / green
😊 / 2
변수의 범위: 바깥에서 만든 변수는 블록 안에서도 수정할 수 있습니다. if·for·switch 블록 안에서 처음 만든 변수는 그 블록이 끝나면 사라집니다.

커서 위치 지정

치환한 뒤 입력을 이어갈 위치와 이동 순서를 지정합니다. 다음·이전 위치로 이동하는 키는 일반 설정의 단축키를 따릅니다.

고정 커서 위치

{{#0}} · {{#1}} · {{cursor}}

번호가 작은 위치부터 이동합니다. 같은 번호는 같은 이동 단계입니다. {{cursor}}와 {{#cursor}}는 0번 위치의 별칭입니다.

예제 보기
본문
Name: {{#0}}
Email: {{#1}}

치환 후 Name 뒤에서 입력을 시작하고, 다음 위치 이동 키로 Email 뒤에 이동합니다.

계산한 커서 위치

{{# expression}}

0 이상의 정수가 되는 변수나 계산식으로 커서 번호를 지정합니다.

예제 보기
본문
{{set $step = 2}}Name: {{# $step + 1}}

Name 뒤에 3번 커서 위치를 만듭니다.

조건에 따라 분기하기

조건에 맞는 본문만 삽입합니다. 여는 태그와 닫는 태그를 짝지어 작성하세요.

if · elif · else

{{if condition}}…{{elif condition}}…{{else}}…{{endif}}

if 조건부터 확인하고 처음 참이 되는 본문을 사용합니다. elif와 else는 필요할 때만 추가합니다.

예제 보기
트리거
/task ${type:\w+}
본문
{{if $type == 'bug'}}\
[BUG]\
{{elif $type == 'feature'}}\
[FEATURE]\
{{else}}\
[TASK]\
{{endif}}
직접 입력할 텍스트
/task bug
결과
[BUG]

/task bug는 [BUG], /task feature는 [FEATURE], 나머지 값은 [TASK]를 삽입합니다. 각 줄 끝의 역슬래시(\)는 줄바꿈을 제거하여 결과를 한 줄로 만듭니다. 생략하면 선택된 본문의 줄바꿈도 삽입됩니다.

switch · case · default

{{switch value}}…{{case value}}…{{endcase}}…{{endswitch}}

한 값을 여러 후보와 비교합니다. case에는 쉼표로 여러 값을 적을 수 있습니다. 일치하는 case가 없으면 default 본문을 사용하며 default도 enddefault로 닫습니다.

예제 보기
트리거
/grade ${grade:[A-Z]}
본문
{{switch $grade}}
{{case 'A', 'B'}}\
Pass\
{{endcase}}
{{default}}\
Review\
{{enddefault}}
{{endswitch}}
직접 입력할 텍스트
/grade A
결과
Pass

A 또는 B이면 Pass, 그 밖의 값이면 Review를 삽입합니다. case·default 본문 밖의 줄바꿈은 무시되므로 switch 뒤와 endcase·enddefault 뒤에는 역슬래시(\)가 필요 없습니다. 예제의 역슬래시는 선택된 본문 안의 줄바꿈만 제거합니다.

반복하기

숫자로 횟수를 지정하거나 list·string·range의 원소를 순회합니다.

횟수로 반복

{{for count}}…{{index}}…{{endfor}}

숫자를 넣으면 해당 횟수만큼 반복합니다. index는 현재 반복 값이며 0부터 시작합니다. 캡처한 숫자 문자열을 횟수로 쓰려면 num()이나 int()로 변환하세요.

예제 보기
본문
{{for 3}}[{{index}}]{{endfor}}
결과
[0][1][2]

범위로 반복

{{for start~end}}…{{endfor}}

range에서도 index는 0부터 시작하는 위치이고 value는 현재 범위 값입니다. value가 시작값부터 끝값까지 1씩 증가하거나 감소하며 양 끝을 포함합니다. 변수에 저장한 range도 사용할 수 있습니다.

예제 보기
본문
{{for 2~5}}[{{index}}:{{value}}]{{endfor}}
결과
[0:2][1:3][2:4][3:5]

리스트와 문자열 순회

{{for iterable}}…{{index}}…{{value}}…{{endfor}}

모든 iterable 반복에서 index는 0부터 시작하는 위치, value는 현재 원소입니다. 중첩 반복문이 끝나면 바깥쪽 index·value로 돌아옵니다. $value 같은 일반 변수와는 별개입니다. 숫자로 횟수를 지정한 반복에서만 value와 index가 같습니다. 문자열 "3"은 한 글자를 순회하므로, 숫자 캡처를 횟수로 쓰려면 num()이나 int()로 변환하세요.

예제 보기
본문
{{for ["red", "blue"]}}{{index}}:{{value}};{{endfor}}
{{for "A😊"}}[{{value}}]{{endfor}}
결과
0:red;1:blue;
[A][😊]

반복 중단과 건너뛰기

{{break}} · {{continue}}

break는 가장 가까운 반복문을 끝내고, continue는 현재 반복의 남은 본문을 건너뜁니다. 태그 앞까지 만든 출력은 유지됩니다.

예제 보기
본문
{{for 1~5}}{{if value == 2}}{{continue}}{{endif}}{{if value == 4}}{{break}}{{endif}}[{{value}}]{{endfor}}
결과
[1][3]

문자열 다루기

함수에는 문자열을 직접 넣거나 $변수를 전달할 수 있습니다. 문자열 위치는 0부터 셉니다.

대소문자와 공백

upper(text) · lower(text) · capitalize(text) · trim(text)

upper와 lower는 전체 대소문자를, capitalize는 첫 글자를 대문자로 바꿉니다. trim은 앞뒤 공백을 제거합니다.

예제 보기
본문
{{upper(trim('  hello  '))}}
결과
HELLO

길이·자르기·바꾸기

len(text) · substr(text, start, length) · replace(text, old, new)

len은 길이를, substr은 시작 위치부터 지정한 길이의 문자열을 반환합니다. replace는 일치하는 텍스트를 바꿉니다.

예제 보기
본문
{{substr('Snippet++', 0, 7)}}
결과
Snippet

문자열을 리스트로 나누기

split(text, separator)

구분 문자열을 기준으로 나누어 list를 반환합니다. 빈 구분 문자열도 사용할 수 있습니다. 구분자는 정규표현식이 아닌 일반 문자열이며, 연속된 구분자 사이의 빈 항목도 유지됩니다.

예제 보기
본문
{{split('red,blue,green', ',')}}
결과
["red","blue","green"]

리스트를 문자열로 합치기

join(list, separator)

리스트의 원소 사이에 구분 문자열을 넣어 하나의 문자열로 합칩니다. 빈 구분 문자열은 공백 없이 이어 붙입니다. 첫 인수는 list여야 하며, null·undefined 원소는 빈 문자열로 처리합니다.

예제 보기
본문
{{join(['red', 'blue', 'green'], ' / ')}}
결과
red / blue / green

시작과 끝 확인

startswith(text, prefix) · endswith(text, suffix)

지정한 문자열로 시작하거나 끝나는지 참·거짓으로 반환합니다. if 조건에 사용할 수 있습니다.

예제 보기
본문
{{if endswith('report.csv', '.csv')}}CSV{{else}}Other{{endif}}
결과
CSV

타입과 숫자 다루기

값의 타입을 확인하고, 숫자로 변환하거나 계산할 수 있습니다. 캡처한 숫자 문자열을 계산할 때는 먼저 숫자로 변환하세요.

값의 타입 확인

type(value)

값의 타입을 string, number, boolean, range, list, null, undefined 중 하나의 문자열로 반환합니다. 캡처 변수는 숫자처럼 보여도 string이며, num()이나 int()로 변환하면 number가 됩니다. 정의하지 않은 변수는 오류입니다.

예제 보기
본문
{{type('42')}}
{{type(num('42'))}}
{{type(true)}}
{{type(2~5)}}
{{type(null)}}
{{type(undefined)}}
결과
string
number
boolean
range
null
undefined

값의 형식 바꾸기

str(value) · num(value) · int(value)

str은 문자열로, num은 숫자로 바꿉니다. int는 소수점 아래를 버려 정수로 바꿉니다.

예제 보기
본문
{{int('10.5') + 1}}
결과
11

반올림과 최솟값·최댓값

round(n) · ceil(n) · floor(n) · min(a, b, …) · max(a, b, …)

round는 반올림, ceil은 올림, floor는 내림입니다. min과 max는 전달한 값 중 가장 작거나 큰 값을 고릅니다.

예제 보기
본문
{{round(3.6)}} / {{min(8, 3, 5)}}
결과
4 / 3

범위나 목록에서 무작위 선택

random(start~end) · random(a, b, …)

range를 전달하면 양 끝을 포함한 무작위 정수를 반환합니다. 여러 인수를 전달하면 그중 하나를 고릅니다.

예제 보기
본문
{{random(1~6)}}
{{random('red', 'blue', 'green')}}

첫 줄에는 1~6 중 하나, 둘째 줄에는 red·blue·green 중 하나가 삽입됩니다.

고유 식별자 생성

uuid()

무작위 UUID v4 식별자를 생성합니다.

예제 보기
본문
ID: {{uuid()}}

날짜·페이지·클립보드

현재 시각이나 치환을 실행하는 페이지의 정보를 가져옵니다.

날짜와 시간

date(format) · time(format) · datetime(format)

형식을 생략하면 기본 형식을 사용합니다. YYYY·MM·DD는 날짜, HH·mm·ss는 시각, ddd·dddd는 요일입니다. 대소문자를 구분합니다.

예제 보기
본문
{{date('YYYY/MM/DD')}} {{time('HH:mm')}}

실행한 시점의 날짜와 시각을 표시합니다.

현재 페이지 정보

url() · domain() · title()

현재 페이지의 전체 주소, 도메인, 제목을 가져옵니다.

예제 보기
본문
{{title()}}
{{url()}}

클립보드에서 붙여넣기

paste()

클립보드의 텍스트를 가져와 삽입합니다.

예제 보기
본문
Pasted: {{paste()}}

클립보드에 복사하기

copy(value)

값을 문자열로 바꾸어 클립보드에 복사합니다. 변수·계산식·스니펫 함수의 결과도 전달할 수 있으며, 본문에는 아무것도 삽입하지 않습니다.

예제 보기
본문
{{copy('Hello, Guest!')}}

클립보드에 Hello, Guest!를 복사합니다. {{copy(upper('hello'))}}처럼 계산한 값을 복사할 수도 있습니다.

입력받기·알림 표시

치환 중에 값을 입력받거나 토스트 알림을 표시할 수 있습니다.

텍스트 입력받기

prompt(message)

입력창을 띄우고 사용자가 입력한 값을 반환합니다. 취소하면 치환을 중단하고 원래 트리거를 복원합니다.

예제 보기
본문
Hello, {{prompt('Name')}}!

목록에서 선택받기

choice(title, option1, option2, …)

선택 메뉴를 띄우고 고른 항목을 반환합니다. 숫자키 1~9로도 선택할 수 있습니다.

예제 보기
본문
Priority: {{choice('Priority', 'Low', 'Normal', 'High')}}

토스트 알림

toast(message, color)

메시지와 CSS 색상으로 6초간 알림을 표시합니다. 본문에는 아무것도 삽입하지 않습니다. 색상은 #22c55e, red, rgb(...) 등을 사용할 수 있고, 새 알림은 이전 알림을 대체합니다.

예제 보기
본문
{{toast('Done', '#22c55e')}}

Done 알림이 초록색 강조로 표시됩니다.

다른 스니펫을 함수로 호출하기

같은 그룹에 있는 스니펫의 본문을 재사용합니다. 서브그룹이 달라도 호출할 수 있습니다.

이름으로 호출하고 인수 전달

{{@hello('Guest')}}

@ 뒤에 스니펫 이름을 적습니다. 호출할 스니펫의 트리거에 정의한 캡처 변수가 왼쪽부터 매개변수가 되며, 인수 개수가 일치해야 합니다. 이름이 없거나 중복되면 오류입니다. 본문의 함수 이름을 더블클릭하면 해당 스니펫으로 이동합니다.

예제 보기
스니펫 이름
hello
트리거
/hello ${name:\w+}
본문
Hello, {{$name}}!
호출하는 본문
{{@hello('Guest')}}
결과
Hello, Guest!

공백이 있는 이름 호출

{{@"hello world"('Guest')}}

공백이나 특수문자가 있는 이름은 큰따옴표 또는 작은따옴표로 감쌉니다. 따옴표 안의 이름은 저장된 스니펫 이름과 정확히 일치해야 합니다.

예제 보기
스니펫 이름
hello world
트리거
/hello ${name:\w+}
본문
Hello, {{$name}}!
호출하는 본문
{{@"hello world"('Guest')}}
결과
Hello, Guest!

작은따옴표로 이름을 감싼 @'hello world'("Guest")도 같습니다.

호출 결과의 커서 번호 이동

{{@func()<2>}} · {{@func<2>()}}

선택적인 <이동량>을 () 앞이나 뒤에 붙입니다. 값은 0 이상의 정수이며 생략하면 0입니다. 변수와 계산식도 사용할 수 있습니다. {{cursor}}와 {{#cursor}}는 0번으로 계산하고, 중첩 호출의 이동량은 누적됩니다.

예제 보기
스니펫 이름
func
본문
hello{{#0}}{{#1}}
호출하는 본문
{{@func()<2>}}
결과
hello{{#2}}{{#3}}

@func<2>()도 같은 결과입니다. 변수로 이동하려면 @func()<$offset + 1>처럼 작성하세요.

호출한 스니펫은 전달받은 인수로 별도의 변수 범위를 사용합니다. 호출자의 변수를 자동으로 공유하지 않으며, 재귀 호출은 허용하지 않습니다.

줄바꿈·이전 문자 삭제

본문의 공백과 줄바꿈은 기본적으로 그대로 삽입됩니다.

코드는 여러 줄로, 결과는 한 줄로

\

줄 끝에 역슬래시(\)를 붙이면 다음 줄과의 줄바꿈과 다음 줄의 들여쓰기를 제거합니다. 긴 태그를 읽기 쉽게 나눌 때 사용할 수 있습니다.

예제 보기
본문
{{set $name = 'Guest'}}\
Hello, {{$name}}!
결과
Hello, Guest!

backspace() · bs()

백스페이스 동작으로 앞의 문자 하나를 삭제합니다.

예제 보기
본문
ABC{{bs()}}D
결과
ABD
