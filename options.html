    스니펫 테스트

    아래 입력창에 트리거를 직접 입력해 치환을 테스트하세요. 현재 편집 내용이 바로 적용되며, 테스트에서는 사이트 제한을 적용하지 않습니다. 커서 이동·되돌리기 단축키도 사용할 수 있습니다.

    문법 가이드

    처음이라면 위에서부터 읽어보세요. 필요한 문법은 오른쪽 목차로 찾아가고, 각 항목의 예제를 펼쳐 확인할 수 있습니다.

    기본 문법

    트리거는 직접 입력하는 단축어이고, 본문은 대신 삽입할 텍스트입니다. 본문의 {{…}} 안에 변수·계산식·함수 등을 적습니다.

    텍스트와 태그

    text {{expression}}

    일반 텍스트는 그대로 삽입됩니다. {{…}} 안의 표현식 결과를 삽입하며, fragment의 실제 커서는 유지됩니다. null과 undefined는 아무 텍스트도 삽입하지 않습니다.

    예제 보기
    트리거
    /total
    본문
    Total: {{2 + 3}}
    직접 입력할 텍스트
    /total
    결과
    Total: 5

    문자열과 함수 인수

    "text" · 'text' · function(arg1, arg2)

    문자열은 큰따옴표 또는 작은따옴표로 감쌉니다. 문자열 안의 \"와 \'는 따옴표 한 문자, \\는 역슬래시 한 문자, \n은 줄바꿈, \t는 탭으로 변환됩니다. \d처럼 그 외의 이스케이프는 그대로 유지합니다. 함수 인수는 쉼표로 구분하고 따옴표는 반드시 닫아야 합니다.

    예제 보기
    본문
    {{replace("Hello, world", "world", "Guest")}}
    결과
    Hello, Guest

    타입과 명시적 변환

    값의 타입과 변환 규칙을 먼저 알아두면 함수 인수와 커서 표현식을 정확하게 작성할 수 있습니다.

    사용할 수 있는 타입

    타입 예시 의미
    string "text" 따옴표로 감싼 텍스트·캡처 값
    number 123 · 1.5 정수·소수
    bool true · false 참·거짓
    fragment `text{{#1}}` 텍스트와 실제 커서를 함께 담는 값
    list [1, "a"] 여러 타입의 원소를 담는 순서 있는 목록
    range 1~3 양 끝을 포함하는 정수 범위
    null null 명시적으로 비어 있는 값
    undefined {{set $value}} 선언만 한 변수·toast()의 반환값

    any는 매개변수에서 모든 타입을 허용한다는 뜻이며 실제 값의 타입이 아닙니다. unknown은 분석기가 타입을 확정하지 못했다는 표시입니다. string | number는 두 타입 중 하나가 될 수 있다는 추론 결과입니다.

    값의 타입 확인

    type(value)

    type(value)는 string, number, bool, fragment, list, range, null, undefined 중 타입 이름을 string으로 반환합니다. 캡처 변수와 스니펫 호출 매개변수는 string으로 시작하지만 set으로 다시 대입하면 타입이 바뀔 수 있습니다. 스니펫 호출의 반환값은 fragment입니다. 선언하지 않은 변수는 오류이며, 선언만 한 변수의 값은 undefined입니다.

    예제 보기
    본문
    {{type('42')}}
{{type(num('42'))}}
{{type(true)}}
{{type(2~5)}}
{{type(null)}}
{{type(undefined)}}
    결과
    string
number
bool
range
null
undefined

    값의 형식 바꾸기

    str(value) · num(value) · int(value)

    str(value)는 string을 반환하며 fragment의 커서는 {{#번호}} 텍스트가 됩니다. num(value)는 숫자로 변환하고, int(value)는 텍스트 앞부분을 정수로 읽습니다. 예를 들어 int("10.5")는 10입니다. num·int에서 변환에 실패하면 0입니다. 이 함수들은 명시적 변환이므로 모든 타입을 인수로 받습니다.

    예제 보기
    본문
    {{int('10.5') + 1}}
    결과
    11

    bool로 변환하기

    bool(value)

    bool(value)는 if와 같은 기준으로 참·거짓을 판정합니다. false, 숫자 0, NaN, null, undefined, 빈 문자열, 정확히 "false" 또는 "0"인 문자열은 false입니다. fragment는 문자열 표현으로 판정하므로 빈 fragment는 false, 커서만 있는 fragment는 true입니다. 빈 list와 range를 포함한 나머지 값은 true입니다. 반환값의 type()은 "bool"입니다.

    예제 보기
    본문
    {{bool("false")}} / {{bool(42)}} / {{bool(``)}} / {{bool(`{{#1}}`)}} / {{type(bool("yes"))}}
    결과
    false / true / false / true / bool

    함수 인수는 자동 변환하지 않음

    함수 인수는 다른 타입으로 자동 변환되지 않습니다. 예를 들어 substr(1234, 1, 2) 대신 substr(str(1234), 1, 2)를 사용합니다. 캡처 변수는 string이므로 숫자 매개변수에는 num()이나 int()로 변환해서 전달합니다. join()의 리스트에는 string 또는 fragment만 넣을 수 있습니다.

    예제 보기 
    {{substr(str(12345), 1, 2)}}
    결과
    23

    트리거에서 변수 받기

    입력한 텍스트의 일부를 변수에 담아 본문에서 재사용할 수 있습니다.

    캡처와 변수 사용

    ${name:regex:flags} → {{$name}}

    트리거에는 ${name:regex:flags}, 본문에는 $name을 사용합니다. 숫자 모양으로 캡처해도 초기 타입은 string입니다. num() 또는 int()로 명시적으로 변환해 계산하세요. 플래그는 생략할 수 있고 ${name}은 공백이 아닌 텍스트를 캡처합니다.

    정규표현식의 중괄호 문자는 \{와 \}로 이스케이프합니다.

    예제 보기
    트리거
    /issue ${id:\d+}
    본문
    Issue #{{$id}}
    직접 입력할 텍스트
    /issue 123
    결과
    Issue #123

    변수·연산·범위·리스트

    캡처한 값이나 직접 저장한 값을 계산에 사용할 수 있습니다.

    값 없이 변수 선언

    {{set $name}}

    값을 생략하면 undefined가 저장됩니다. 변수는 나중에 값을 넣어 사용할 수 있고, 값을 넣기 전에 출력하면 빈 문자열이 됩니다. 기존 변수에 다시 사용하면 값이 undefined로 초기화됩니다.

    예제 보기
    본문
    {{set $value}}{{type($value)}}
    결과
    undefined

    변수 저장과 수정

    {{set $name = expression}}

    set은 값을 저장하고 본문에는 아무것도 삽입하지 않습니다. 이미 있는 값은 +=, -=, *=, /=, %=로 수정할 수 있습니다. 쉼표로 여러 할당이나 선언을 나눌 수 있습니다. 예: {{set $a = 3, $b = 5}}. 왼쪽부터 순서대로 적용하므로 뒤의 식에서 앞에서 바꾼 값을 사용할 수 있습니다. 문자열·함수·리스트 안의 쉼표는 할당을 나누지 않습니다.

    예제 보기
    본문
    {{set $a = 3, $b = 5}}{{$a}} + {{$b}} = {{$a + $b}}
    결과
    3 + 5 = 8

    계산과 비교

    + - * / % · == != > >= < <= · && ||

    괄호로 계산 순서를 정합니다. 비교는 ==·!=·>·>=·<·<=, 논리 연산은 &&·||를 사용하며 결과는 bool입니다. 논리 부정 연산자 !는 지원하지 않습니다. bool 값의 반대 여부는 == false로 비교하세요. 조건 ? 참일_때 : 거짓일_때에서 선택한 식만 실행하며 &&·||도 필요할 때만 오른쪽 식을 실행합니다. 문자열·fragment는 0 이상의 정수와 *로 반복할 수 있습니다. 함수 인수와 달리 연산자·조건식은 자체 규칙을 사용하므로 숫자 계산은 num()·int()로 타입을 명확히 하세요.

    예제 보기
    본문
    Average: {{(80 + 100) / 2}}
    결과
    Average: 90

    정수 범위(range)

    start~end

    양 끝을 포함하는 정수 범위입니다. 2~5는 2, 3, 4, 5이며 5~2는 역순입니다. 양 끝에 number 변수나 계산식을 쓸 수 있고, 변수에 저장하거나 random()과 for에서 사용할 수 있습니다. 스니펫 호출 인수는 string만 허용하므로 range를 직접 전달할 수 없습니다.

    예제 보기
    본문
    {{set $min = 2}}
{{set $range = $min~($min + 3)}}

    $range에 2~5 범위가 저장됩니다. 아래의 반복하기와 무작위 선택에서 사용할 수 있습니다.

    반복 가능한 값(iterable)

    list, string, fragment는 iterable입니다. for로 원소를 순회하고 insertAt·removeAt으로 편집한 새 값을 만듭니다. range는 읽기 전용입니다. string은 유니코드 문자 단위이며, fragment는 유니코드 문자와 커서를 각각 원소 하나로 셉니다. type()은 list, string, fragment, range를 반환합니다.

    리스트 저장과 사용

    {{set $items = [1, 2, 3]}}

    대괄호 안에 쉼표로 원소를 구분합니다. 숫자·문자열·변수·계산식·다른 리스트를 넣을 수 있고, []는 빈 리스트입니다. type()은 list, len()은 원소 개수를 반환합니다. 직접 출력하면 [1,2,3] 형태로 표시하며 문자열 원소에는 큰따옴표가 붙습니다.

    예제 보기
    본문
    {{set $items = [1, 2, 3]}}\
{{type($items)}} / {{len($items)}} / {{$items}}
    결과
    list / 3 / [1,2,3]

    리스트 연결

    list + list · {{set $items += [value]}}

    두 리스트를 이어 붙인 새 리스트를 반환합니다. 원본은 바뀌지 않습니다. 양쪽 값이 모두 list여야 합니다.

    예제 보기
    본문
    {{([1, 2] + [3, 4])}}
    결과
    [1,2,3,4]

    값으로 원소 제거

    list - list · {{set $items -= [value]}}

    오른쪽 리스트의 값과 같은 원소를 모두 제거한 새 리스트를 반환합니다. 원본과 나머지 원소의 순서는 유지합니다.

    예제 보기
    본문
    {{[1, 2, 2, 3] - [2]}}
    결과
    [1,3]

    인덱스로 원소 삽입

    insertAt(iterable, index, value)

    list·string·fragment의 정수 index 앞에 값을 삽입합니다. list에는 모든 타입의 원소 하나를 넣을 수 있지만 string·fragment 대상에는 string 또는 fragment만 넣을 수 있습니다. string에 fragment를 넣으면 결과도 fragment입니다. len(target)은 맨 뒤, -1은 마지막 원소 앞이며 범위 밖이면 그대로입니다. 원본은 바뀌지 않고 range에는 사용할 수 없습니다.

    예제 보기
    본문
    {{set $items = [10, 30]}}\
{{set $items = insertAt($items, 1, 20)}}\
{{$items}}
{{insertAt("AC", 1, "B")}}
    결과
    [10,20,30]
ABC

    인덱스로 원소 제거

    removeAt(iterable, index)

    list·string·fragment에서 index 위치의 원소를 제거한 새 값을 반환합니다. 0은 첫 원소, -1은 마지막 원소입니다. fragment의 커서는 하나의 원소로 제거됩니다. 범위 밖 정수 인덱스는 내용을 바꾸지 않습니다. 읽기 전용 range에는 사용할 수 없습니다. 변수를 갱신하려면 반환값을 다시 대입하세요.

    예제 보기
    본문
    {{set $items = [10, 20, 30]}}\
{{set $items = removeAt($items, -1)}}\
{{$items}}
{{removeAt("A😊B", 1)}}
    결과
    [10,20]
AB

    iterable 원소 읽기

    $items[0] · $items[-1] · $items[1][0]

    list·string·fragment·range에 [index]로 접근합니다. 0은 첫 원소, -1은 마지막 원소입니다. string은 유니코드 문자 단위입니다. fragment는 문자와 커서를 각각 하나로 세며 해당 원소 하나를 담은 fragment를 반환합니다. range는 순회 순서의 숫자를 반환합니다. 정수 인덱스만 허용하며 범위 밖이면 undefined입니다. 중첩 접근과 함수 결과에도 사용할 수 있습니다.

    예제 보기
    본문
    {{set $items = ['red', 'blue', 'green']}}\
{{$items[0]}} / {{$items[-1]}}
{{"A😊B"[1]}} / {{(5~2)[-1]}}
    결과
    red / green
😊 / 2
    변수의 범위: 바깥에서 만든 변수는 블록 안에서도 수정할 수 있습니다. if·for·switch 블록 안에서 처음 만든 변수는 그 블록이 끝나면 사라집니다.

    fragment와 커서 보존

    커서를 포함한 본문을 값으로 다룰 때는 string 대신 fragment를 사용합니다.

    스니펫 결과인 fragment

    fragment는 일반 텍스트와 실제 커서를 함께 보관하는 값입니다. 백틱 리터럴과 스니펫 호출이 fragment를 만듭니다. 변수에 저장하거나 +로 연결하고 *로 반복해도 커서가 보존됩니다. len(), 인덱스 접근, for는 유니코드 문자와 커서를 각각 원소 하나로 셉니다. str()은 커서 문법까지 일반 문자열로 바꾸며, 스니펫 호출의 매개변수에는 string으로 변환해서 전달해야 합니다.

    예제 보기
    본문
    {{set $f = @field()}}{{type($f)}} / {{len($f)}} / {{str($f)}}
    결과
    fragment / 5 / ab{{#1}}cd

    fragment 리터럴

    `text{{#1}}`

    백틱(`) 안에 본문 문법을 적어 fragment를 만듭니다. {{…}}, 커서 태그, 분기·반복, 스니펫 호출을 사용할 수 있으며 안쪽 대입은 바깥 변수에 영향을 주지 않습니다. 백틱 본문에서는 \`과 \\만 각각 백틱·역슬래시로 변환됩니다. \n과 \t는 그대로이며 실제 줄바꿈은 유지됩니다. 태그 내부의 따옴표 문자열에는 문자열 이스케이프 규칙이 적용됩니다.

    예제 보기
    본문
    {{set $f = `ab{{#1}}cd`}}{{type($f)}} / {{len($f)}} / {{hasCursor($f)}} / {{str($f)}}
    결과
    fragment / 5 / true / ab{{#1}}cd

    문자열을 fragment로 변환하기

    fragment(value)

    fragment(value)는 문자열을 백틱 리터럴과 같은 본문 문법으로 해석합니다. 커서 태그, 계산식, 변수, 분기·반복을 사용할 수 있습니다. 이미 fragment이면 그대로 반환합니다. 현재 변수를 읽으며 안쪽의 대입은 바깥 변수에 영향을 주지 않습니다. 그 외 값은 먼저 텍스트로 바꾸고 null과 undefined는 빈 텍스트로 처리합니다.

    예제 보기
    본문
    {{set $text = "ab{{#1}}cd", $f = fragment($text)}}{{type($f)}} / {{len($f)}} / {{hasCursor($f)}}
    결과
    fragment / 5 / true

    커서인지 확인하기

    isCursor(fragment)

    isCursor(fragment)는 커서 하나로만 구성된 fragment이면 true를 반환합니다. 텍스트가 섞이거나 커서가 여러 개이면 false입니다. 빈 fragment나 텍스트만 있는 fragment도 false입니다. 인수는 fragment만 허용하며 string 등 다른 타입은 오류입니다. fragment 반복문의 value나 인덱스로 읽은 원소를 검사할 때 사용합니다.

    예제 보기
    본문
    {{for @field()}}{{if isCursor(value)}}[cursor]{{else}}{{value}}{{endif}}{{endfor}}
    결과
    ab[cursor]cd

    커서가 포함되어 있는지 확인하기

    hasCursor(fragment)

    hasCursor(fragment)는 실제 커서가 하나라도 포함되면 true, 없으면 false입니다. 텍스트가 섞이거나 커서가 여러 개여도 true입니다. 인수는 fragment만 허용합니다. isCursor()는 커서 하나로만 구성됐는지를 확인한다는 차이가 있습니다. 문자열이나 str(fragment)를 검사하려면 먼저 fragment()로 명시적으로 변환해야 하며, 이 변환은 텍스트를 본문 문법으로 다시 해석합니다.

    예제 보기
    본문
    {{set $f = @field()}}{{isCursor($f)}} / {{hasCursor($f)}} / {{hasCursor(`plain text`)}}
    결과
    false / true / false

    커서 위치 지정

    치환한 뒤 입력을 이어갈 위치와 이동 순서를 지정합니다. 다음·이전 위치로 이동하는 키는 일반 설정의 단축키를 따릅니다.

    고정 커서 위치

    {{#0}} · {{#1}} · {{cursor}}

    작은 번호부터 이동하며 같은 번호는 같은 단계입니다. {{cursor}}와 {{#cursor}}는 0번 별칭입니다. 본문·백틱 리터럴·fragment()로 해석한 본문의 커서 태그가 실제 커서를 만듭니다. 일반 문자열·캡처·prompt()·paste() 값 안의 커서 문법은 그대로는 텍스트입니다.

    예제 보기
    본문
    Name: {{#0}}
Email: {{#1}}

    치환 후 Name 뒤에서 입력을 시작하고, 다음 위치 이동 키로 Email 뒤에 이동합니다.

    계산한 커서 위치

    {{# expression}}

    커서 번호는 0 이상의 안전한 정수인 number여야 합니다. string은 자동 변환하지 않으므로 캡처한 숫자는 num() 또는 int()로 변환해서 사용하세요.

    예제 보기
    본문
    {{set $step = 2}}Name: {{# $step + 1}}

    Name 뒤에 3번 커서 위치를 만듭니다.

    조건에 따라 분기하기

    조건에 맞는 본문만 삽입합니다. 여는 태그와 닫는 태그를 짝지어 작성하세요.

    if · elif · else

    {{if condition}}…{{elif condition}}…{{else}}…{{endif}}

    if부터 조건을 확인하고 처음 참이 되는 본문을 사용합니다. elif와 else는 선택 사항입니다. if·elif에는 조건식이 필요하며 {{if }}처럼 비워둘 수 없습니다. 조건 판정은 bool()과 같은 기준이고, 선택되지 않은 본문은 실행하지 않습니다.

    예제 보기
    트리거
    /task ${type:\w+}
    본문
    {{if $type == 'bug'}}\
[BUG]\
{{elif $type == 'feature'}}\
[FEATURE]\
{{else}}\
[TASK]\
{{endif}}
    직접 입력할 텍스트
    /task bug
    결과
    [BUG]

    /task bug는 [BUG], /task feature는 [FEATURE], 나머지 값은 [TASK]를 삽입합니다. 각 줄 끝의 역슬래시(\)는 줄바꿈을 제거하여 결과를 한 줄로 만듭니다. 생략하면 선택된 본문의 줄바꿈도 삽입됩니다.

    switch · case · default

    {{switch value}}…{{case value}}…{{endcase}}…{{endswitch}}

    한 값을 여러 후보와 비교합니다. case에는 쉼표로 여러 값을 적을 수 있습니다. 일치하는 case가 없으면 default 본문을 사용하며 default도 enddefault로 닫습니다.

    예제 보기
    트리거
    /grade ${grade:[A-Z]}
    본문
    {{switch $grade}}
{{case 'A', 'B'}}\
Pass\
{{endcase}}
{{default}}\
Review\
{{enddefault}}
{{endswitch}}
    직접 입력할 텍스트
    /grade A
    결과
    Pass

    A 또는 B이면 Pass, 그 밖의 값이면 Review를 삽입합니다. case·default 본문 밖의 줄바꿈은 무시되므로 switch 뒤와 endcase·enddefault 뒤에는 역슬래시(\)가 필요 없습니다. 예제의 역슬래시는 선택된 본문 안의 줄바꿈만 제거합니다.

    반복하기

    숫자로 횟수를 지정하거나 list·string·fragment·range의 원소를 순회합니다.

    횟수로 반복

    {{for count}}…{{index}}…{{endfor}}

    숫자를 넣으면 해당 횟수만큼 반복합니다. index는 현재 반복 값이며 0부터 시작합니다. 캡처한 숫자 문자열을 횟수로 쓰려면 num()이나 int()로 변환하세요.

    예제 보기
    본문
    {{for 3}}[{{index}}]{{endfor}}
    결과
    [0][1][2]

    범위로 반복

    {{for start~end}}…{{endfor}}

    range에서도 index는 0부터 시작하는 위치이고 value는 현재 범위 값입니다. value가 시작값부터 끝값까지 1씩 증가하거나 감소하며 양 끝을 포함합니다. 변수에 저장한 range도 사용할 수 있습니다.

    예제 보기
    본문
    {{for 2~5}}[{{index}}:{{value}}]{{endfor}}
    결과
    [0:2][1:3][2:4][3:5]

    list·string·fragment 순회

    {{for iterable}}…{{index}}…{{value}}…{{endfor}}

    iterable 반복에서 index는 0부터 시작하는 위치, value는 현재 원소입니다. fragment는 유니코드 문자 또는 커서 하나를 담은 fragment를 반환하므로 value를 출력하면 커서가 보존됩니다. 중첩 반복 후에는 바깥 index·value로 돌아옵니다. value는 $value와 별개입니다. 숫자 횟수 반복에서만 value와 index가 같습니다. 숫자 텍스트를 횟수로 쓰려면 num()이나 int()로 변환하세요.

    예제 보기
    본문
    {{for ["red", "blue"]}}{{index}}:{{value}};{{endfor}}
{{for "A😊"}}[{{value}}]{{endfor}}
    결과
    0:red;1:blue;
[A][😊]

    반복 중단과 건너뛰기

    {{break}} · {{continue}}

    break는 가장 가까운 반복문을 끝내고, continue는 현재 반복의 남은 본문을 건너뜁니다. 태그 앞까지 만든 출력은 유지됩니다.

    예제 보기
    본문
    {{for 1~5}}{{if value == 2}}{{continue}}{{endif}}{{if value == 4}}{{break}}{{endif}}[{{value}}]{{endfor}}
    결과
    [1][3]

    텍스트와 fragment 다루기

    문자열과 fragment에 대소문자 변경, 자르기, 나누기·합치기를 적용합니다. 위치는 0부터 세며 fragment의 커서는 원소 하나로 취급합니다.

    대소문자와 공백

    upper(text) · lower(text) · capitalize(text) · trim(text)

    upper와 lower는 텍스트의 대소문자를, capitalize는 첫 텍스트 문자를 대문자로 바꿉니다. trim은 앞뒤 공백을 제거합니다. fragment를 받으면 커서를 보존한 fragment를 반환합니다. trim은 가장자리에서 커서를 만나면 그 안쪽의 공백을 제거하지 않습니다.

    예제 보기
    본문
    {{upper(trim('  hello  '))}}
    결과
    HELLO

    길이·자르기·바꾸기

    len(text) · substr(text, start[, length]) · replace(text, old, new)

    len은 iterable 길이를 number로 반환합니다. substr은 string 또는 fragment에서 number 시작 위치와 선택적인 길이를 받습니다. string의 substr 위치는 UTF-16 단위이며 fragment는 유니코드 문자와 커서를 각각 하나로 셉니다. replace는 처음 일치한 부분을 바꿉니다. fragment가 관련된 자르기·바꾸기는 커서를 보존합니다. 다른 타입은 자동 변환하지 않습니다.

    예제 보기
    본문
    {{substr('Snippet++', 0, 7)}}
    결과
    Snippet

    텍스트를 리스트로 나누기

    split(text, separator)

    string 또는 fragment를 구분자로 나눠 list를 만듭니다. 구분자는 정규식이 아니며 빈 항목도 보존합니다. 빈 구분자로 fragment를 나누면 유니코드 문자 또는 커서 하나를 담은 fragment들이 됩니다. fragment 구분자는 실제 커서 노드와도 일치할 수 있습니다.

    예제 보기
    본문
    {{split('red,blue,green', ',')}}
    결과
    ["red","blue","green"]

    리스트를 텍스트로 합치기

    join(list, separator)

    string 또는 fragment 원소만 담은 list와 string 또는 fragment 구분자를 받습니다. 원소 사이에 구분자를 넣어 합치며 원소나 구분자가 fragment이면 커서를 보존한 fragment, 아니면 string을 반환합니다. number·null·undefined 등은 자동 변환하지 않으므로 리스트에 넣기 전에 str()로 변환하세요.

    예제 보기
    본문
    {{join(['red', 'blue', 'green'], ' / ')}}
    결과
    red / blue / green

    값이 포함되어 있는지 확인하기

    includes(iterable, value)

    string·fragment에서는 부분 텍스트를 검색하며 검색 값도 string 또는 fragment여야 합니다. 실제 커서와 문자열의 커서 문법은 구별합니다. list에서는 타입 변환 없이 원소 전체를 비교하므로 모든 타입을 검색할 수 있습니다. range에서는 number를 받아 양 끝 사이의 정수인지 확인합니다. 빈 텍스트는 모든 텍스트에 포함되며, 다른 타입을 텍스트로 자동 변환하지 않습니다.

    예제 보기
    본문
    {{set $f = @field()}}{{includes("abcd", "bc")}} / {{includes([1, 2, 3], 2)}} / {{includes(5~2, 3)}} / {{includes($f, $f[1] + $f[2])}}
    결과
    true / true / true / true

    시작과 끝 확인

    startswith(text, prefix) · endswith(text, suffix)

    지정한 텍스트 또는 fragment로 시작하거나 끝나는지 반환합니다. fragment를 비교할 때 실제 커서 노드와 문자열의 커서 문법은 서로 다릅니다.

    예제 보기
    본문
    {{if endswith('report.csv', '.csv')}}CSV{{else}}Other{{endif}}
    결과
    CSV

    숫자와 무작위 값

    number 값을 계산하거나, 후보·정수 범위에서 무작위 값을 고릅니다.

    반올림과 최솟값·최댓값

    round(n) · ceil(n) · floor(n) · min(a, b, …) · max(a, b, …)

    round는 반올림, ceil은 올림, floor는 내림입니다. min과 max는 하나 이상의 number 인수 중 가장 작거나 큰 값을 반환합니다. 모든 인수는 number여야 하므로 숫자 문자열은 num() 또는 int()로 먼저 변환하세요.

    예제 보기
    본문
    {{round(3.6)}} / {{min(8, 3, 5)}}
    결과
    4 / 3

    범위나 목록에서 무작위 선택

    random(start~end) · random(a, b, …)

    range를 전달하면 양 끝을 포함한 무작위 정수를 반환합니다. 여러 인수를 전달하면 그중 하나를 고릅니다. 리스트를 하나의 인수로 넣으면 원소를 뽑는 대신 리스트 자체를 반환합니다.

    예제 보기
    본문
    {{random(1~6)}}
{{random('red', 'blue', 'green')}}

    첫 줄에는 1~6 중 하나, 둘째 줄에는 red·blue·green 중 하나가 삽입됩니다.

    고유 식별자 생성

    uuid()

    무작위 UUID v4 식별자를 생성합니다.

    예제 보기
    본문
    ID: {{uuid()}}

    다른 스니펫을 함수로 호출하기

    같은 그룹에 있는 스니펫의 본문을 재사용합니다. 서브그룹이 달라도 호출할 수 있습니다.

    이름으로 호출하고 인수 전달

    {{@hello('Guest')}}

    @ 뒤에 스니펫 이름을 적습니다. 호출할 스니펫의 트리거에 정의한 캡처 변수가 왼쪽부터 매개변수가 되며, 인수 개수가 일치해야 합니다. 모든 인수는 string이어야 하며, 다른 타입은 str()로 명시적으로 변환해야 합니다. 이름이 없거나 중복되면 오류입니다. 본문의 함수 이름을 더블클릭하면 해당 스니펫으로 이동합니다.

    예제 보기
    스니펫 이름
    hello
    트리거
    /hello ${name:\w+}
    본문
    Hello, {{$name}}!
    호출하는 본문
    {{@hello('Guest')}}
    결과
    Hello, Guest!

    공백이 있는 이름 호출

    {{@"hello world"('Guest')}}

    공백이나 특수문자가 있는 이름은 큰따옴표 또는 작은따옴표로 감쌉니다. 따옴표 안의 이름은 저장된 스니펫 이름과 정확히 일치해야 합니다.

    예제 보기
    스니펫 이름
    hello world
    트리거
    /hello ${name:\w+}
    본문
    Hello, {{$name}}!
    호출하는 본문
    {{@"hello world"('Guest')}}
    결과
    Hello, Guest!

    작은따옴표로 이름을 감싼 @'hello world'("Guest")도 같습니다.

    호출 결과의 커서 번호 이동

    {{@func()<2>}} · {{@func<2>()}}

    선택적인 <이동량>을 () 앞이나 뒤에 붙입니다. 값은 0 이상의 정수이며 생략하면 0입니다. 변수와 계산식도 사용할 수 있습니다. {{cursor}}와 {{#cursor}}는 0번으로 계산하고, 중첩 호출의 이동량은 누적됩니다.

    예제 보기
    스니펫 이름
    func
    본문
    hello{{#0}}{{#1}}
    호출하는 본문
    {{@func()<2>}}
    결과
    hello{{#2}}{{#3}}

    @func<2>()도 같은 결과입니다. 변수로 이동하려면 @func()<$offset + 1>처럼 작성하세요.

    호출한 스니펫은 전달받은 인수로 별도의 변수 범위를 사용합니다. 호출자의 변수를 자동으로 공유하지 않으며, 재귀 호출은 허용하지 않습니다.

    날짜·페이지·클립보드

    현재 시각이나 치환을 실행하는 페이지의 정보를 가져옵니다.

    날짜와 시간

    date([format]) · time([format]) · datetime([format])

    형식을 생략하면 기본 형식을 사용합니다. YYYY·MM·DD는 날짜, HH·mm·ss는 시각, ddd·dddd는 요일입니다. 대소문자를 구분합니다.

    예제 보기
    본문
    {{date('YYYY/MM/DD')}} {{time('HH:mm')}}

    실행한 시점의 날짜와 시각을 표시합니다.

    현재 페이지 정보

    url() · domain() · title()

    현재 페이지의 전체 주소, 도메인, 제목을 가져옵니다.

    예제 보기
    본문
    {{title()}}
{{url()}}

    클립보드에서 붙여넣기

    paste()

    클립보드의 텍스트를 가져와 삽입합니다.

    예제 보기
    본문
    Pasted: {{paste()}}

    클립보드에 복사하기

    copy(value)

    string 또는 fragment를 클립보드에 복사하고 빈 문자열을 반환합니다. fragment의 커서는 {{#번호}} 형태의 텍스트로 기록됩니다. 숫자 등 다른 타입은 str()로 명시적으로 변환하세요. 클립보드 쓰기에 실패하면 오류가 발생합니다.

    예제 보기
    본문
    {{copy('Hello, Guest!')}}

    클립보드에 Hello, Guest!를 복사합니다. {{copy(upper('hello'))}}처럼 계산한 값을 복사할 수도 있습니다.

    입력받기·알림 표시

    치환 중에 값을 입력받거나 토스트 알림을 표시할 수 있습니다.

    텍스트 입력받기

    prompt(message)

    입력창을 띄우고 사용자가 입력한 값을 반환합니다. 취소하면 치환을 중단하고 원래 트리거를 복원합니다.

    예제 보기
    본문
    Hello, {{prompt('Name')}}!

    목록에서 선택받기

    choice(title, option1, option2, …)

    선택 메뉴를 띄우고 고른 항목을 반환합니다. 숫자키 1~9로도 선택할 수 있습니다.

    예제 보기
    본문
    Priority: {{choice('Priority', 'Low', 'Normal', 'High')}}

    토스트 알림

    toast(message, color[, seconds])

    메시지와 CSS 색상으로 알림을 표시합니다. 세 번째 인수로 표시 시간(초)을 지정하며 생략하면 6초입니다. undefined를 반환하며 본문에는 아무것도 삽입하지 않습니다. 색상은 #22c55e, red, rgb(...) 등을 사용할 수 있고, 새 알림은 이전 알림을 대체합니다.

    예제 보기
    본문
    {{toast('Done', '#22c55e', 3)}}

    Done 알림이 초록색 강조로 3초간 표시됩니다.

    줄바꿈·이전 문자 삭제

    본문의 공백과 줄바꿈은 기본적으로 그대로 삽입됩니다.

    코드는 여러 줄로, 결과는 한 줄로

    \

    줄 끝에 역슬래시(\)를 붙이면 다음 줄과의 줄바꿈과 다음 줄의 들여쓰기를 제거합니다. 긴 태그를 읽기 쉽게 나눌 때 사용할 수 있습니다.

    예제 보기
    본문
    {{set $name = 'Guest'}}\
Hello, {{$name}}!
    결과
    Hello, Guest!

    앞의 문자 삭제

    backspace() · bs()

    백스페이스 동작으로 앞의 문자 하나를 삭제합니다.

    예제 보기
    본문
    ABC{{bs()}}D
    결과
    ABD

    타입 추론·오류·경고

    실행 전에 문제를 확인하고, 그룹 요약이나 툴팁에서 필요한 위치와 타입을 찾습니다.

    위치에 따라 달라지는 추론 타입

    변수 툴팁은 해당 위치에서 가능한 타입을 보여줍니다. 재대입·분기·반복에 따라 타입이 달라질 수 있습니다. 함수 이름에 마우스를 올리거나 호출을 작성하면 매개변수·반환 타입과 오버로드 후보를 볼 수 있습니다. 인수 타입이 정해지면 후보가 좁혀지며, 화살표로 전환하고 현재 입력 중인 매개변수를 확인할 수 있습니다. 스니펫 호출의 매개변수는 string, 반환값은 fragment입니다.

    오류와 경고의 차이

    허용 타입과 전혀 맞지 않으면 빨간 오류, 일부 타입만 맞거나 unknown이면 노란 경고입니다. 오류는 실행을 막습니다. 경고는 실행할 수 있지만 실제 값이 타입 규칙과 맞지 않으면 실행 중 오류가 납니다. 예를 들어 string | number를 string 매개변수로 전달하면 경고입니다.

    그룹에서 문제 찾기

    그룹 상단의 오류 및 경고를 접으면 건수를, 펼치면 스니펫별 메시지와 위치를 볼 수 있습니다. 항목을 클릭하면 검색 필터가 해제되고 스니펫·서브그룹이 펼쳐지며 해당 위치로 이동합니다. 접힌 스니펫이나 검색으로 숨긴 스니펫의 진단도 집계합니다.

    내장 함수 타입 표

    같은 이름의 함수라도 인수 타입에 따라 서로 다른 시그니처를 가집니다. 각 행은 오버로드 하나이며, 호출 툴팁은 입력한 인수에 맞는 후보만 보여줍니다.

    ?는 선택 인수, ...는 가변 인수입니다. list<string | fragment>는 해당 타입의 원소만 담은 리스트이며 contains<fragment>는 fragment 원소가 하나 이상 필요하다는 뜻입니다. 툴팁의 이전·다음 화살표로 가능한 오버로드를 전환할 수 있습니다.
